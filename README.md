# CSV CLI Dashboard

A command-line tool for viewing and searching student data stored in a CSV file. Made in Python as a semester project.

## Features
- Show columns
- Count rows
- Search a student by name (not case-sensitive)

## How to run
python dashboard.py

## Concepts used
File handling, csv module, loops, conditionals, lists, user input
